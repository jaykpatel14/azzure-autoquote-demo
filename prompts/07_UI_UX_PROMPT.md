# Phase 7 — UI/UX Prompt

Refine the SaaS interface using the Azzure palette:
- warm ivory #FFF6E7
- deep burgundy #4F0C28
- powder blue #A6C0D8
- charcoal #271F20

Build:
- onboarding;
- dashboard;
- new estimate;
- image upload progress;
- AI processing states;
- editable estimate form;
- quote preview;
- quote history;
- customers;
- pricing settings;
- team management;
- usage and billing;
- admin support screens.

Requirements:
- responsive;
- accessible keyboard navigation;
- clear loading/error/empty states;
- WCAG-aware contrast;
- no exposure of internal margin or cost fields to customer-facing quote recipients;
- customer quote shows only the approved estimated final price;
- final-price disclaimer;
- confirmation before destructive actions.

Preserve all backend validations; UI validation is additional, not a replacement.
